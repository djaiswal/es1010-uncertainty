Quantifying uncertainty in tree biomass · page 4 of 4

From 25 Trees to a Plot

What you are looking at. On page 3, the biomass of one tree was uncertain by about ± 40 %. Here we add up 25 example trees, like the ones measured in a Miyawaki plot. Each tree is still ± 40 %. But the total of the 25 trees is uncertain by only about ± 12 %. Why? Because random errors partly cancel when you add many trees: one tree comes out too high, another too low, and the total ends up close to the truth.

But not all errors cancel. Some errors are shared by many trees: the same wood-density value is used for every tree of a species, and the same equation is used for all 25 trees. If the equation is 1 % too high, every tree is 1 % too high, and the total is also 1 % too high. Shared errors do not cancel. This page lets you watch both effects.

Words used on this page

AGB
Above-ground biomass. The dry weight of trunk, branches and leaves, in kg.
Point value
The number from the plain equation with no uncertainty. The point total is the sum of the 25 point values: 286 kg.
Round
One round of the simulation: every one of the 25 trees gets one random set of errors, the 25 biomasses are added, and the sum goes into the pile. (Page 3 called this a "draw" for one tree.)
SD
Standard deviation. One number that measures spread: roughly the typical distance of a value from the mean.
CV
Coefficient of variation. SD ÷ mean × 100, a percentage. The relative error. On this page a spread written as a percentage is always a CV. An SD always has a unit (m, cm, kg).
ε and σ
ε (epsilon) is the scatter of one tree around the equation, on the log scale: Doubt 2 from page 2. σ (sigma) is its SD, 0.357, with no unit. A scatter with σ = 0.357 is a CV of about 37 %, rounded on these pages to 40 %.
Median
The middle value when all the rounds are sorted.
95 % interval
The range that holds the middle 95 % of the rounds. Also called the 95 % range.
Whisker
A horizontal line drawn through a dot to show its 95 % interval. A long whisker means a large uncertainty.
Shared error
An error that is the same for many trees at once. Example: the wood-density value for a species. Also called a systematic error.
Independent error
An error that is different for every tree, with no connection between trees. Example: a reading error in the height of one tree. Also called a random error.
√n
The square root of n. √25 = 5. Adding n equal, independent trees divides the relative error by √n.
Hectare (ha)
An area of 10,000 m² (100 m × 100 m). Forest results are usually reported per hectare.

BEFORE PANEL B · A SMALL EXAMPLE, BY HAND

Three trees first

Panel B does for 25 trees what this box does for three. Read this once, slowly, and Panel B will be easy. The three trees are three rows from the example table above, and they are three different species. (The table prints 3.99 kg for tree #1; here it is rounded to 4.0 kg.)

Step 1 · The plain answer for each tree, then add

Each tree gets its own weight from the same equation. The total of the plot is the three weights added together. That is all "adding up trees" means.

AGB = 0.0673 × (ρ × D² × H)^0.976 Tree #1 T. bellirica D = 4.9 cm H = 4.4 m ρ = 0.62 size value = 0.62 × 4.9² × 4.4 = 65.5 AGB = 4.0 kg Tree #14 P. cineraria D = 5.1 cm H = 5.1 m ρ = 0.75 size value = 0.75 × 5.1² × 5.1 = 99.5 AGB = 6.0 kg Tree #8 P. guajava D = 6.8 cm H = 5.2 m ρ = 0.70 size value = 0.70 × 6.8² × 5.2 = 168.3 AGB = 10.0 kg Point total = 4.0 + 6.0 + 10.0 = 20.0 kg

Step 2 · Each tree alone is uncertain by about ± 40 %

On page 3 we saw that one tree's weight from the equation has a CV of about 40 %, almost all of it from the scatter die (a real tree is not on the line). Written as an SD in kg, and as a 95 % interval (from ÷ 2 to × 2):

Tree #1 4.0 kg SD = 0.40 × 4.0 = 1.6 kg 95 % interval about 2.0 to 8.0 kg Tree #14 6.0 kg SD = 0.40 × 6.0 = 2.4 kg 95 % interval about 3.0 to 12.0 kg Tree #8 10.0 kg SD = 0.40 × 10.0 = 4.0 kg 95 % interval about 5.0 to 20.0 kg

The bigger tree has the bigger SD in kg, although all three have the same 40 %. This is what Panel A showed: on a log scale every whisker is the same length.

Step 3 · One round: roll a die for every tree, multiply, then add

A round is one possible world. In a round, every tree gets its own roll of the scatter die. The roll is a multiplying factor: a factor of 1.4 means "this tree is really 40 % heavier than the equation says", a factor of 0.7 means "30 % lighter". We multiply each tree's weight by its own factor, then add the three results. (To keep the arithmetic short, this box rolls only the scatter die. The page rolls all five.)

Total of a round = (4.0 × factor for #1) + (6.0 × factor for #14) + (10.0 × factor for #8) Round 1 #1: 4.0 × 1.4 = 5.6 #14: 6.0 × 0.7 = 4.2 #8: 10.0 × 1.0 = 10.0 total = 5.6 + 4.2 + 10.0 = 19.8 kg 1 % below 20.0 Round 2 #1: 4.0 × 1.2 = 4.8 #14: 6.0 × 1.3 = 7.8 #8: 10.0 × 1.1 = 11.0 total = 4.8 + 7.8 + 11.0 = 23.6 kg 18 % above 20.0 Round 3 #1: 4.0 × 0.8 = 3.2 #14: 6.0 × 0.9 = 5.4 #8: 10.0 × 0.7 = 7.0 total = 3.2 + 5.4 + 7.0 = 15.6 kg 22 % below 20.0 Round 4 #1: 4.0 × 0.6 = 2.4 #14: 6.0 × 1.5 = 9.0 #8: 10.0 × 0.9 = 9.0 total = 2.4 + 9.0 + 9.0 = 20.4 kg 2 % above 20.0

Round 1: tree #1 went up by 40 %, tree #14 went down by 30 %, tree #8 did not move. One up and one down: they cancelled, and the total is only 1 % away from 20.0 kg. Round 4: the same thing, tree #1 far down and tree #14 far up, total 2 % away.

Round 2: all three went up. Round 3: all three went down. Nothing cancelled in these rounds, so the total moved a lot, by 18 % and 22 %. This can happen, but it is not common: for three independent dice to all go the same way is like three coins all landing on the same side, all heads or all tails: about 1 round in 4. With 25 trees it is like 25 coins all landing on the same side, which almost never happens. That is why the total of many trees stays close to the point total.

Now do this 20,000 times and write down every total. Panel B builds exactly such a pile, for 25 trees. The middle of the pile is a little above 20.0 kg, near 21 kg (the note under Panel B explains why), and its spread is the uncertainty of the plot total.

Step 4 · How big is the spread of the total? Square, add, square root

We do not need 20,000 rounds to guess the answer. When the errors are independent (every tree rolls its own die), the SDs in kg combine by the same rule as on page 3:

SD of total = √(SD₁² + SD₁₄² + SD₈²) = √(1.6² + 2.4² + 4.0²) = √(2.6 + 5.8 + 16.0) = √24.4 = 4.9 kg CV of total = 4.9 ÷ 20.0 = 25 % (each tree alone was 40 %) 95 % interval of the total: roughly 20.0 − 2 × 4.9 to 20.0 + 2 × 4.9 = about 10 to 30 kg

So three trees added together are known to 25 %, better than any one of them at 40 %. Not as good as the textbook 40 % ÷ √3 = 23 %, because that rule is for three equal trees. Here tree #8 is half the total, so its die matters most, and the plot behaves like 2.6 equal trees, not 3. Panel C shows the same thing for 25 trees: both curves, blue and green, stay above the dashed √n line.

Step 5 · A shared error does not cancel

So far every tree rolled its own die. Some errors are not like that. The equation (a and b) is the same for all three trees. If it is 1 % too high, all three trees are 1 % too high in the same round. They move together, never one up and one down. There is nothing to cancel.

Equation 1 % too high → #1: 4.0 × 1.01 = 4.04 #14: 6.0 × 1.01 = 6.06 #8: 10.0 × 1.01 = 10.10 total = 20.2 kg (+1 %)

For a shared error the total moves by the same percentage as each tree. It does not shrink by the square-add-root rule, and it does not shrink however many trees you add. Add 1,000 trees that all use the same equation, and the 1 % is still there. That is why the green curve in Panel C never reaches zero: the shared part is a floor.

Wood density is shared too, but only within a species. Our three trees are three different species, so each uses its own density value from the table, and their density errors are independent, like the scatter: they cancel. On the full page it is different: six of the 25 trees are T. bellirica and all six use the same value 0.62. If that value is 10 % too high, all six go up by 10 % together. In Panel B, if you switch off the H, D and scatter dice and leave only ρ on, you can watch the six T. bellirica trees move in the same direction in every round.

The whole page in three lines. Each round: weight of every tree with its own rolled errors, then add them up. Independent errors shrink in the total by the square-add-root rule. Shared errors do not shrink. Panel B shows the rounds, Panel C shows the shrinking, and the "give every tree its own error" box above switches the shared errors off so you can see the difference.

Why is the mean of the rounds higher than the point total? The point total is 286 kg, but the mean of the rounds comes out near 306 kg, about 7 % higher. Reason: the scatter factor eε is not symmetric. Its 95 % range runs from factor 0.5 (half as heavy) to factor 2.0 (twice as heavy). A factor of 2.0 adds 100 %; a factor of 0.5 removes only 50 %. So, averaged over many rounds, each tree comes out about 7 % heavier than the plain equation says (the exact factor is eσ²/2 = 1.066). For one tree the median was equal to the point value (page 3). For a sum of many trees this is no longer true: the pile of totals is nearly symmetric, so its median (about 304 kg) sits close to its mean, about 6 % above the point total. Report the median and the 95 % interval. And remember: adding up plain-equation values for many trees under-estimates the plot by a few percent.

Per hectare

Field plots are small. Reports give results "per hectare" (10,000 m²). To convert, divide by the plot area and multiply by 10,000. This keeps the same percentage uncertainty. The numbers get bigger, and the interval gets bigger with them.

Area = number of trees ÷ density. Change either the density or the area; the other one is updated. If you change the number of trees away from 25, the total is multiplied by (trees ÷ 25). This assumes the 25 measured trees are typical of the others.

Carbon = 0.47 × biomass (dry wood is about 47 % carbon). CO₂ = 3.67 × carbon (44 ÷ 12, the weight of CO₂ made from one unit of carbon).

Caution: this is a big jump from a small plot. Going from about 8 m² to 10,000 m² means multiplying by roughly 1,200. The interval shown covers only the measurement and equation uncertainty of these 25 trees. It says nothing about a second kind of uncertainty, the sampling uncertainty: if you had measured a different 8 m² of the same planting, you would have got a different total. Chave et al. (2004, Philosophical Transactions of the Royal Society B, volume 359, pages 409–420) found that sampling error alone is about 10 % for a plot of 0.25 hectare and about 5 % for 1 hectare. For a plot of a few square metres it is far larger. A per-hectare number from one tiny plot must be reported with this warning next to it. Sanity check (does the number make sense?): at 3 trees per m², these 25 example trees give roughly 340 to 370 tonnes per hectare. That is what a fully grown tropical rainforest carries, not a young planting. So something is off. Possible reasons: the real density is lower than 3 per m²; the example D and H values are too large; or the equation (built from natural forest trees with D ≥ 5 cm) gives too-high values for small, crowded, planted trees. A result that fails a sanity check is not a failure. It is a finding: write it down and name the possible reasons.

What to notice

  • Adding up trees makes random error smaller. Each tree is ± 40 %; the total of 25 trees is about ± 12 %. High and low errors cancel. This is why foresters measure many trees instead of measuring one tree very carefully.
  • But the error does not fall as fast as 40 % ÷ √n. With 25 equal trees the CV would be 40 ÷ √25 = 8 %. Our trees are very unequal: the two biggest make up a third of the total. So the plot behaves like fewer than 25 trees, and the green curve in Panel C stays above the dashed line.
  • Shared errors do not get smaller. Tick the "give every tree its own error" box: the curve drops further. In reality, every tree of a species uses the same density value and every tree uses the same equation. That part of the error is systematic. It stays the same however many trees you add. With very many trees it becomes a floor below which the CV cannot go.
  • Mean and median are different when the pile is not symmetric. The scatter pushes the mean about 7 % above the point total, and for a sum of many trees the median is pushed up almost as much. Report the median and the 95 % interval.
  • Per-hectare numbers from tiny plots are a big jump. The interval covers measurement and equation error only. The sampling error ("which 8 m² did we pick?") is extra, and probably bigger.
