# es1010-uncertainty

Interactive pages and student guide on quantifying uncertainty in tree biomass (bootstrap, Monte Carlo, Chave 2014) — Ecology & Environment 2026, IIT Palakkad.

- `index.html` — landing page linking everything below
- `Quantifying_Uncertainty_Tree_Biomass_Student_Guide.pdf` — the student guide
- `1_dice_bootstrap.html` — probability as frequency, averages of dice, the bootstrap
- `2_equation_born.html` — how an allometric equation is fitted; parameter vs residual uncertainty
- `3_one_tree_montecarlo.html` — Monte Carlo for one tree
- `4_from_trees_to_plot.html` — 25 trees added up; per hectare
